# Карта F1 Predict — Understand Anything

Карта проекта находится в `knowledge-graph.json`. Описания, слои и обучающий маршрут — на русском.

Публичный интерактивный просмотр: https://konicaru.github.io/f1-predict/map/ — без токена и локального сервера. GitHub Actions собирает закреплённую версию viewer и публикует сохранённый в Git граф вместе с приложением при пуше в `main`.

Запуск из корня проекта в PowerShell:

```powershell
.\.ua\start-dashboard.ps1
```

Откройте адрес `Dashboard URL`, который сервер напечатает в терминале, целиком с параметром `?token=...`. Для остановки нажмите Ctrl+C. Сервер слушает только локальный адрес 127.0.0.1.

Локальная копия Understand Anything и её зависимости лежат в `tooling/` и исключены из Git. Для запуска не требуется глобальный pnpm. Исходный код игрового приложения и его зависимости не изменяются этой установкой.

Автообновление включено (`autoUpdate: true`). Правило в корневом `AGENTS.md` требует инкрементального обновления после коммитов в сессии Codex, а также проверки актуальности при начале работы. Коммит вне агента сам по себе не запускает ИИ-анализ: изменения будут обнаружены в следующей сессии. Можно также попросить: «Обнови карту Understand Anything нашего проекта на русском». Инструкции и скрипты анализа находятся в `tooling/understand-anything/understand-anything-plugin/skills/understand/`.

Исключения для анализа заданы в `.understandignore`. Секреты, сборки, служебные каталоги и старая карта исключены. Исторические планы присутствуют как документация; реализованное поведение следует проверять по коду.

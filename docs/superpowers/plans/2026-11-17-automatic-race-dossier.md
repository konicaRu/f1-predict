# Автоматическое досье трассы — план реализации

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans. Выполнять последовательно в текущей сессии.

**Goal:** Автоматически дополнять открытие прогнозов досье трассы, а напоминания — свежей погодой на часы гонки.

**Architecture:** Node.js получает календарь и историю по circuitId из Jolpica, почасовую погоду из Open-Meteo. Проверенные постоянные характеристики хранятся в небольшом реестре со ссылками на источники. Telegram Rich Message объединяет изображение и текст; при явном отказе API используется обычный HTML без повторной отправки после сетевого таймаута.

**Tech Stack:** Существующие CommonJS, Node 20 fetch/node:test, Telegram Bot API, GitHub Actions.

**Spec:** Согласованные пользователем макет `docs/mockups/telegram-las-vegas-dossier.html` и порядок работ в беседе: данные → погода → карточка → локальная проверка, без отправки в канал.

## Ограничения

- Никаких изменений БД, секретов, действующих результатов и пользовательских данных.
- Существующий гейт raceweek_announced_at сохраняется; отметка только после успешной отправки.
- История выбирается по circuitId, а не названию города; пять последних завершённых гонок до текущего этапа.
- Прошлый год — именно предыдущий сезон; лучшие круг гонки и квалификацию не смешивать.
- Рекорд и перепад высот — только при наличии проверенного источника. Первое полное досье — Las Vegas; для остальных трасс работают история и погода, а неподтверждённые характеристики опускаются.
- Вероятность дождя — максимум почасовой вероятности в окне гонки, не вероятность дождя за всю гонку. Температура грунта не заменяет температуру асфальта.
- Внешние источники ограничены по времени; сбой одной части не блокирует анонс.
- Публикация в Telegram и push не входят в текущую проверку.

## Review Focus

- Гонка пересекает полночь UTC/МСК: расчёт по UTC, отображение МСК.
- Устаревший прогноз, null вместо 0, неполное покрытие окна: не показывать достоверные числа.
- Изменился раунд/трасса: сверять сезон, раунд и дату календаря.
- Меньше пяти гонок, нет прошлогодней гонки, дождевая квалификация: честные подписи и доступные данные.
- Таймаут отправки: не отправлять fallback, поскольку первое сообщение могло дойти.

## Журнал решений

- Работа в текущем checkout: здесь уже лежат согласованные незакоммиченные макеты; не переносить и не смешивать изменения карты `.ua`.
- Не добавлять Python/FastF1 в горячий путь уведомлений: для согласованных показателей достаточно Jolpica и погодного API. FastF1 понадобится для следующего этапа статистики SC/сходов и телеметрии.
- Автокоммит не выполнять: пользователь сейчас разрешил реализацию, текущий результат подготовить к проверке.

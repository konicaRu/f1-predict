# Automatic mobile dossier card implementation plan

**Goal:** Подключить согласованную HTML-карточку к реальным автоматическим анонсам и напоминаниям Telegram.

**Design:** Каждая отправка получает свежие историю и погоду, создаёт HTML и PNG в Chromium, отправляет одно фото с краткой подписью и настоящей кнопкой конкретной гонки. Напоминание сохраняет список не проголосовавших в день дедлайна. При недоступности Chromium или явном отказе Telegram — обычный текст с той же кнопкой. При неоднозначном сетевом сбое повторов нет. Прежние расписание, проверки сроков и маркеры доставки сохраняются.

**Architecture:** Переиспользовать buildDossierCard и текущую загрузку досье. buildDossierMessage формирует HTML карточки и подпись; deliverDossier отрисовывает через Playwright и отправляет sendPhoto. Старый текстовый fallback сохраняется. GitHub Actions устанавливает Chromium перед отправками, включая подстраховочный raceweek на других режимах.

**Tech stack:** Node.js 20+, Playwright 1.65.1, Chromium, Telegram Bot API.

## Constraints

Не запускать живые notify.js при проверках. Не менять БД или маркеры ради теста. PNG и временные файлы не публиковать в репозитории; браузер закрывается в finally. Внешние данные экранируются, браузер не загружает внешние ресурсы. Для трассы без характеристик остаются данные истории/погоды и явные заглушки.

**Validation:** 24 теста досье и 32 проверки notify пройдены. Реальная PNG-карточка проверена браузером, рабочий transport проверен без живой отправки. Независимый review: блокирующих замечаний нет. Активация — публикация этого изменения в main; первый Ubuntu-прогон проверяется GitHub Actions до отправки.

# Формат досье по дням недели

По уточнению пользователя новая большая карточка отправляется только в понедельник и четверг.
В среду остаётся прежний Rich Message с небольшим баннером, погодой и кнопкой прогноза.
День определяется по Europe/Moscow, включая подстраховочные анонсы на других cron-режимах.
Время отправок, гейт анонса и список не проголосовавших не меняются.

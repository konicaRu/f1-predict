# Mobile dossier card implementation plan

**Goal:** Отправить в чат настоящий вариант одной графической карточки с крупными шрифтами и рабочей кнопкой прогноза.

**Design:** Сохранить графитовый стиль и красные акценты. HTML-шаблон формирует изображение шириной 1080 px; подписи от 36 px, имена от 44 px. Прошлогодние результаты расположены широкими строками. Ветер указывается на начало гонки (откуда дует), скорость — максимум первых двух часов. Под картинкой настоящая inline-кнопка Telegram, без нарисованной кнопки. Нет данных — явная подпись. Использовать реальные источники и ID гонки; не менять маркер отправленного анонса и расписание при разовой проверке.

**Approach:** Переиспользовать текущую загрузку досье; добавить HTML-рендерер вместо изображения от генеративной модели. HTML выбран ради точного текста и дальнейшего автоматического обновления. На этом этапе подготовить и отправить реальный пост для проверки, подключение к расписанию — отдельное действие после оценки.

- [x] Добавить тесты направления ветра: границы 0/360, пустые и некорректные значения, отсутствие направления при штиле.
- [x] Запрашивать wind_direction_10m; сохранять направление часа начала гонки.
- [x] Реализовать HTML карточки с крупными шрифтами и корректными отсутствующими значениями.
- [x] Проверить тесты, получить актуальные данные, отрендерить PNG браузером и визуально проверить.
- [x] Отправить карточку с настоящей кнопкой в настроенный чат, не изменяя БД.

**Validation:** npm test --prefix scripts/telegram; визуальная проверка PNG; подтверждение Telegram API message_id.

**Result:** HTML/PNG проверены в браузере (1080×2257, переполнений нет), тесты уведомлений пройдены. Настоящий пост отправлен: Telegram message_id=182; кнопка predict_24. Расписание и маркеры БД не изменены.

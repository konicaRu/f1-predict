# Understand Anything — автоматическое обновление карты

Пользователь разрешил автоматическое инкрементальное обновление карты проекта после Git-коммитов. Настройка: `.ua/config.json`, поле `autoUpdate`.

При начале работы, а также после успешного `git commit`, `git merge`, `git cherry-pick` или `git rebase`:

1. Если `autoUpdate` не равно `true` или отсутствует `.ua/meta.json`, ничего не запускать.
2. Сравнить `git rev-parse HEAD` с `gitCommitHash` из `.ua/meta.json`. При совпадении ничего не запускать.
3. Если HEAD изменился, прочитать и выполнить `.ua/tooling/understand-anything/understand-anything-plugin/hooks/auto-update-prompt.md`. Корень плагина — `.ua/tooling/understand-anything/understand-anything-plugin`; не искать глобальную установку, если эта папка доступна.
4. Обновлять карту на русском без отдельного подтверждения. Соблюдать `.ua/.understandignore`, проверки символов и порядок сохранения базовой линии. При ошибке сохранить предыдущую опубликованную карту и сообщить о сбое; не отмечать её актуальной.

Это правило действует в сессиях агента. Обычный Git-коммит вне агента не запускает ИИ-анализ; такой коммит будет обнаружен при следующей сессии. Не создавать коммиты автоматически ради сохранения самой карты.

Назначение

Закрытая лига прогнозов на топ-10 гонок Формулы-1 для компании друзей. До дедлайна каждый вслепую расставляет прогноз (drag-and-drop), после гонки очки считаются автоматически, по сезону — общий зачёт. В лиге играет и ИИ-участник — GridBot.

Репозиторий: github.com/konicaRu/f1-predict · хостинг фронтенда — GitHub Pages, бэкенд — облачный Supabase.

Стек

React 18 + TypeScript Vite React Router @dnd-kit Supabase (Postgres + Auth) RLS-first безопасность Jolpica API OpenF1 (фолбэк) Gemini API (GridBot) Telegram Bot API Google Sheets API GitHub Actions (cron)

Важно: anon-ключ Supabase публичен по дизайну (лежит в собранном JS-бандле) — вся защита данных на RLS-политиках БД, не на секретности ключа. И — pg_cron нигде не используется, вся автоматика на cron-триггерах GitHub Actions, несмотря на упоминания pg_cron в старых доках.

Прогноз — drag-and-drop через @dnd-kit (PredictionSlots + DriverPool), read-only после дедлайна, серверная валидация состава. Сеть РФ↔Supabase нестабильна → авто-ретрай с backoff в src/lib/db.ts.

Формула очков

points(слот i) = max(0, WEIGHTS[i] − 2·|реальная − заявленная|) + (3, если точное совпадение)

WEIGHTS = [25, 18, 15, 12, 10, 8, 6, 4, 2, 1]   // за P1..P10

Источник истины — SQL-функция score_prediction() (0002); фронтенд-копия в src/lib/scoring.ts только для мгновенного превью. Тайбрейкер: больше точных попаданий → выше место; при равенстве — лучший результат отдельной гонки.

GridBot — ИИ-участник

Обычный аккаунт public.users без отдельного UI, играет по тем же правилам, что и люди. Данные: пул гонки + собственные результаты сезона + 3 прошлых сезона F1 (Jolpica) → промпт → Gemini structured JSON → валидация → фолбэк (сортировка по drivers.standing) при сбое → upsert в predictions → объяснение в Telegram, если Gemini ответила.

Модель — gemini-2.5-flash. Находится по display_name='GridBot', не по UUID — поэтому display_name сделан уникальным (0015). Код — scripts/ai-player/.

Гварды / гочи для нового агента

  • pg_cron нигде не используется — вся автоматика на GitHub Actions cron, несмотря на старые упоминания pg_cron в доках.
  • Результат сразу final, без provisional-стадии — autoresults/fetch.js + set_race_result() пишут final при первом успешном ответе Jolpica/OpenF1.
  • npm run rebuild в scripts/db дропает ВСЕ таблицы в реальной облачной БД — локальной песочницы нет (Docker не работает на машине разработки).
  • Anon-ключ публичен по дизайну — безопасность на RLS, не на секретности ключа.
  • МСК = UTC+3 круглый год — Россия не переходит на летнее время.
  • GitHub Pages из РФ требует VPN — все ссылки на сайт в Telegram сопровождаются пометкой.
  • predictions без DELETE-политики — удаление прогноза запрещено физически.
  • SECURITY DEFINER используется точечно (is_admin, keepalive_ping, set_race_result) — не копировать паттерн на новые функции без явного обоснования.
  • Каждая scripts/*-папка независима — свой package.json и .env-ридер, общий lib сознательно не шарится.
  • Репозиторий публичный — минуты GitHub Actions бесплатны без лимита.
